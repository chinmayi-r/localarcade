Hardware

Installed models

        

          The scan reads directory listings and file metadata only — it opens
          no model files, writes nothing, and the result never leaves this
          machine. Directories read: ~/.ollama/models,
          ~/.lmstudio/models, ~/.cache/lm-studio/models,
          plus any folder you add below.
        

        
        
        

      

      

        
Benchmark

        

          Runs your own llama-bench on a model you already have.
          This currently requires a llama.cpp installation — LM Studio- or
          Ollama-only setups aren't supported for benchmarking yet. Loading
          the model will occupy your GPU/CPU for roughly a minute; a watchdog
          terminates hung runs. Results are measured on this machine and never
          leave it. Numbers reflect llama-bench defaults, which may differ
          from your tuned serving flags — the exact configuration used is
          shown with the result.
